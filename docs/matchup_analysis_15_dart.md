# 討論者 総当たり（Dart実エンジン・15人版・2026-11-12）

> 位置づけ：`matchup_analysis_15.md`（Python再実装シミュレーション）の「未確認」——Dart実エンジンでの総当たりを、テストとして落とし込んだ検証結果。
> 実行テスト：`test/matchup_dart_test.dart`（`flutter test test/matchup_dart_test.dart` で再実行可能）。

## 方法

- `LocalMockDebateEngine` を直接駆動し、`DebateController` のバトルループ（規定ターン到達／`BattleMachine.shouldEarlyFinish` による早期決着／`judgeAndSummarize` の勝敗判定）をタイマーなしで再現。
- 条件は Python 版と同型：お題10種 × 3R/4R/6R × 先手立場（賛成/反対）× 先後入れ替え、各ペア120試合、総計12,600試合。
  - お題は本テストで明示した10種（アプリのサンプルお題6種＋副業／大学／SNS／終身雇用の4種）。Python 版のお題リストは記録が残っていないため、絶対値の完全一致は目指していない。順位・傾向の検証が目的。
- 乱数はモックの既定どおり「お題ハッシュ＋ターン番号シード」で決定的。同条件で再実行すれば同一結果になる。

## Python版との比較（検証結果）

- **順位はほぼ一致**：上位6位（カズ／ひろゆき／マツコ／ホリエモン／黒柳／落合）と最下位（進次郎）は完全一致。差が出たのは隣接する僅差の組だけ——池上 vs 和田（59.8 vs 59.6、実質互角）、細木 vs ジミー（20.5 vs 19.8）。いずれも1pt未満の差で、お題セットや乱数系列の違いの範囲内と見るのが妥当。
- **黒柳徹子AIの5位は実測でも維持**（66.2%）。「ネタ枠寄り」の設計意図とのズレは Python 側の再実装ミスではなく、実装された倍率（反論×1.15・ユーモア×1.2、合計4.05）の帰結であることが Dart 実エンジンでも確認された。
- **後手有利は実測でも全員に残る**。先手→後手の差は +6.5〜+15.7pt（Python版の推定 +2.4〜+7.2pt より大きめに出た。お題セット依存の可能性があるため絶対値の差は断定しないが、方向と「全員共通」は両版一致）。構造原因（中盤フェーズの `turn % 3` 割り当て）は変わらず、バランス調整の「構造修正のみ（案A）」の根拠は実測でも成立する。
- **互角ペア（45:55以内、Dart実測）**：池上×和田 50:50、落合×黒柳 50:50、なんJ民×細木 50:50、なんJ民×ジミー 50:50、細木×ジミー 50:50、ホリエモン×落合 53:47、ホリエモン×黒柳 52:48、落合×和田 52:48、ジミー×出川 52:48、細木×出川 53:47、進次郎×出川 45:55。Python版で挙がった「落合×和田 52:48」「ジミー×出川 52:48」は実測でも再現した。

## バランス調整の判断への含意

- 案A/B/C の効果試算は Python 近似（±1〜2pt）だったが、現行条件の順位と勝率は Dart 実測で裏付けられた。試算の方向性（A は後手有利のみ解消・B はカズ −2.8pt 程度・C は進次郎 +8.8pt 程度）は、現行値が実測でほぼ同じである以上、そのまま判断材料に使ってよい。
- 15人版で追加された論点「黒柳を上位の実力枠として受け入れるか、ネタ枠寄りに下げるか」についても、実測 66.2%（5位）は Python 版と一致。判断は引き続き Nojima 待ちで、コードは未変更。
