## 分析

### 1. 相性らしい相性はほぼなく、序列が支配的

マトリクスはほぼ完全な序列（上位が下位にほぼ必ず勝つ）になっている。ジャンケン的な三つ巴や「Aには弱いがBには強い」という相性の非対称は確認できなかった。

原因はスコア生成の構造：基礎ロール（58〜91）は全員共通の分布で、個人差は ScoreBias（4カテゴリ倍率）のみに由来する。よって強さは実質「倍率合計」で決まり、上表のとおり総合勝率の順位と倍率合計の順位はほぼ一致する。

- カズレーザーが突出：ロジック×1.2・根拠×1.2に加え、反論×1.05・ユーモア×1.15と全カテゴリが1.0以上で「穴がない」。基礎ロールのブレでは覆りにくい。
- ネタ枠3人（関・なんJ民・進次郎）は実力枠7人にはほぼ勝てない（対実力枠の最高勝率は関→修造の13%）。3人の間では 関 ＞ なんJ民 ＞ 進次郎 の序列があり、最弱決定戦（なんJ民 vs 進次郎）は67対33でなんJ民有利。

### 2. 修造は「格下狩り」型

倍率合計3.80は池上・落合と同等だが、総合勝率は39.3%と下回る。特殊特性「逆境燃焼」は劣勢時（勢いシェア45未満）でのみ発動するため、格上相手では発動しても覆せず、格下相手（関87%・なんJ民92%・進次郎93%）には素の倍率で押し切る、という分布になっている。「終盤の逆転キャラ」という設計意図ほどには大逆転が起きていない。

### 3. 構造的な後手有利（全員に共通）

全員が後手時の方が勝率が3〜7ポイント高い。原因は中盤フェーズの割り当て（`_phaseFor` の `turn % 3` ローテーション）：

- 先手は中盤で evidence フェーズ（カテゴリ合計プロファイルが最小：base換算 −42）が多く回る
- 後手は attack フェーズ（反論が満額で合計プロファイル最大：−30）が多く回る

同点時は勢い側（≒先手寄り）が勝つルールがあるが、それでも後手優位は残る。フェーズをラウンド単位（両者が同じフェーズを担当）に変えると、この偏りは解消できる。

### 4. 互角で面白いペア

- 落合陽一 × 池上彰：57対43（最も互角）
- ホリエモン × 落合陽一：58対42
- マツコ × ホリエモン：63対37
- カズレーザー × ひろゆき：78対22（上位同士では最も接近）

### 5. 注意点

- この序列はモックエンジン（＝全エンジン共通のスコア計算構造）のもの。実AI使用時はジャッジAIの裁定が勝敗に入るため、序列は変わり得る。
- ラウンド数が多いほど基礎ロールのブレが平均化され、序列どおりの結果に寄る（番狂わせは3Rで最も起きやすい）。

## バランス調整の候補（未実施）

1. カズレーザーの倍率を微減（例：根拠 1.2→1.1）するか、池上・落合・修造を微増して中位を圧縮する
2. 中盤フェーズをラウンド単位の割り当てに変更し、後手有利を解消する
3. 進次郎のロジック倍率を 0.5→0.7 程度に底上げする（現行の勝率7.6%は「弱いが愛される枠」としても低め）
4. ネタ枠の弱さ自体はキャラ性として意図的に残す選択肢もある（その場合も 2. の後手有利だけは構造問題として切り分けたい）
